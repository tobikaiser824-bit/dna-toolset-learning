# DNA Toolkit – Lernprojekt

Dieses Repository enthält persönliche Übungen und Weiterentwicklungen aus der DNA-Toolkit-Lernserie von **RebelCoderRU**.

Die ursprünglichen Lerninhalte und die historische Commit-Struktur sind entsprechend als Lernreferenz erhalten. Änderungen und Ergänzungen wurden im Rahmen des persönlichen Lernprojekts vorgenommen.

## Inhalt

- DNA- und Proteinsequenz-Verarbeitung
- Transkription und Translation
- Open Reading Frames
- GC-Content-Berechnung
- FASTA-Beispiele

> Hinweis: Vor einer Weiterveröffentlichung sollte die Lizenz beziehungsweise die Erlaubnis zur Weitergabe der ursprünglichen Lerninhalte geprüft werden.
